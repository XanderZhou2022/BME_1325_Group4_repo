# 2026-04-17 问题与解决记录

## 背景

今天主要目标是把后端主机（本机）上的 PostgreSQL 与 FastAPI 跑通，并支持其他同学远程访问（API 与数据库）。

---

## 1. PostgreSQL 初期不可用

### 现象

- `psql --version` 报命令不存在
- `localhost:5432` 不通
- 查不到 PostgreSQL 服务

### 原因

- PostgreSQL 未完整安装，或安装后命令行工具未加入 PATH

### 解决

- 完成 PostgreSQL 安装（版本 18）
- 确认端口 5432 可达
- 用 Python `psycopg` 实测可连接数据库

### 经验

- `psql` 不在 PATH 不代表 PostgreSQL 不能用；先看 5432 和服务状态更可靠。

---

## 2. API 启动报错：`No module named 'app'`

### 现象

- 启动 `uvicorn app.main:app` 时抛出模块找不到

### 原因

- 启动目录错误（在仓库根目录启动，而不是 API 目录）

### 解决

- 进入目录再启动：
  - `BME_1325_Group4_repo/system/backend/api`
- 或使用 `--app-dir` 指定应用目录

### 经验

- 看到 `No module named 'app'`，第一优先检查当前工作目录。

---

## 3. 远程访问 API 失败

### 现象

- 本机可访问 `127.0.0.1:8000`
- 远程设备访问失败

### 原因

- API 仅监听本地回环地址（`127.0.0.1`）

### 解决

- 用公网监听方式启动：
  - `uvicorn app.main:app --host 0.0.0.0 --port 8000`
- 必要时放行防火墙 8000 入站规则

### 经验

- 本机能访问但远程不能，通常先查监听地址是不是 `0.0.0.0`。

---

## 4. 数据库脚本运行顺序问题

### 现象

- `seed_test_data.py` 报表不存在
- `verify_db.py` 校验失败

### 原因

- 并行执行导致 `seed/verify` 早于建表

### 解决

- 严格按顺序执行：
  1. `init_core_tables.py`
  2. `seed_test_data.py`
  3. `verify_db.py`

### 结果

- 最终校验 `Final: PASS`

### 经验

- 建库、建表、种子、校验必须串行，不可并行。

---

## 5. 远程 pgAdmin 连接失败（Host 填写格式）

### 现象

- 报错：`failed to resolve host 'http://100.79.195.68/'`

### 原因

- 在 pgAdmin 的 Host 字段填了 URL（含 `http://` 和 `/`）

### 解决

- Host 只填纯 IP：
  - `100.79.195.68`（Tailscale）
  - 或 `10.19.133.61`（局域网）
- Port 填 `5432`

### 经验

- pgAdmin 的 Host 不是网址输入框，只能填主机名/IP。

---

## 6. PostgreSQL 远程访问配置

### 已确认与修改

- `postgresql.conf`：已是 `listen_addresses='*'`
- `pg_hba.conf`：新增远程网段规则（`scram-sha-256`）
  - `10.19.128.0/21`
  - `100.64.0.0/10`
- 重启服务：`postgresql-x64-18`

### 经验

- 远程连库要同时满足三件事：
  1. 服务监听地址允许远程
  2. `pg_hba.conf` 允许客户端网段
  3. 系统防火墙放行 5432
