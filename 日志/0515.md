# 2026-05-15 工作日志（ICU 多智能体系统）

## 今日目标

围绕“ICU 多智能体系统接入知识库与 LLM 辅助能力”完成一轮架构升级。

本次工作的核心不是让 LLM 替代 agent 做医学判断，而是把现有规则型 agent 纳入统一的：

- knowledge-aware
- LLM-assisted
- human-in-the-loop
- fallback-safe
- audit-ready

架构中。

所有医学相关输出均要求：

- 保留原有规则/结构化判断作为主来源
- 知识库只作为背景解释、摘要组织、沟通草稿和人工复核提醒
- LLM 不做诊断、不做治疗建议、不做资源分配决策
- 输出必须包含 `human_review_required=true`
- LLM 失败或关闭时必须 fallback

接入类型：

- 知识库接入
- 不调用 LLM

作用：

- 对生命体征异常与趋势标签补充背景解释
- 根据 `abnormal_flags` 和 `trend_labels` 检索知识卡
- 生成模板型 `signal_explanation`

新增输出：

- `knowledge_background`
- `signal_explanation`
- `forbidden_use_reminder`
- `knowledge_used`
- `llm_used=false`
- `human_review_required=true`

边界：

- 不诊断
- 不给治疗建议
- 不输出病情确定性结论

### 3. Intervention Tracker Agent 接入

接入类型：

- 知识库接入
- 不调用 LLM

作用：

- 对干预后反应进行背景解释
- 对 non-response / deterioration 模式补充复核理由
- 检索 medication safety 相关知识卡作为背景提醒

新增输出：

- `knowledge_background`
- `response_explanation`
- `medication_safety_context`
- `forbidden_use_reminder`
- `knowledge_used`
- `llm_used=false`
- `human_review_required=true`

边界：

- 不建议加药
- 不建议调剂量
- 不建议更换治疗方案
- 不生成 treatment plan

### 4. Patient Memory Agent 接入

接入类型：

- 知识库接入

作用：

- 生成病程 narrative summarization
- 压缩最近 6h/24h 关键事件

新增输出：

- `short_term_narrative`
- `intervention_response_memory`
- `communication_relevant_context`
- `knowledge_context`
- `forbidden_use_reminder`
- `llm_used`
- `fallback_used`
- `audit_log_id`
- `human_review_required=true`

边界：

- 不做医学判断
- 不推断预后
- 不覆盖原始事件记录

### 5. Ward Coordinator Agent 接入

接入类型：

- 知识库接入
- LLM-assisted

作用：

- 原规则 score 继续决定 priority rank

新增输出：

- `rationale`
- `knowledge_background`
- `global_watch_items`
- `review_reminders`
- `forbidden_use_reminder`
- `llm_used`
- `fallback_used`

- `human_review_required=true`

边界：

- LLM 不允许改排序
- 不自动分配床位
- 不决定 ICU 收治或转出
- 不做治疗建议

### 6. Compassion / Family Communication Agent 新增

新增目录：

- `system/agents/compassion_family_communication/`

## 八、当前架构总结

当前系统已经从原先的规则型多 agent demo，升级为：

```text
规则负责判断
知识库负责背景
LLM 负责解释、摘要和草稿
Orchestrator 负责路由、fallback 和审计
人类负责最终复核
```

核心设计边界保持清晰：

- 风险是否存在：规则判断
- 队列如何排序：规则评分
- 事实来自哪里：数据库与结构化 agent 输出
- 知识库提供什么：背景和措辞依据
- LLM 做什么：解释、摘要、narrative、draft
- LLM 不能做什么：诊断、治疗、资源分配、家属直接沟通
