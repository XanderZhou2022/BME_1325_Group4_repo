## 本地查看数据库（终端）

### 1) 进入数据库

```bash
/opt/homebrew/opt/postgresql@16/bin/psql -d icu_agent
```

### 2) 查看所有表

```sql
\dt
```

### 3) 查看某张表结构（示例）

```sql
\d vital_sign_events
```

### 4) 查询示例

```sql
SELECT admission_id, patient_id, bed_id, status, scenario_tag
FROM admissions
ORDER BY admission_id;
```

```sql
SELECT id, admission_id, timestamp, heart_rate, mean_arterial_pressure, spo2
FROM vital_sign_events
ORDER BY timestamp DESC
LIMIT 10;
```

### 5) 退出 psql

```sql
\q
```

## 用 Python 连接并读取表

> 依赖：`pip install "psycopg[binary]"`

```python
import psycopg

dsn = "dbname=icu_agent user=zhou host=localhost port=5432"

with psycopg.connect(dsn) as conn:
    with conn.cursor() as cur:
        cur.execute("SELECT patient_id, patient_code, name, age FROM patients ORDER BY patient_id;")
        rows = cur.fetchall()
        for row in rows:
            print(row)
```
